# Source and scope

This repository contains the original StockMixer code from [SJTU-DMTai/StockMixer](https://github.com/SJTU-DMTai/StockMixer), `master` commit `cce13598afd3ff33ae317700a85ae08db0554652`.

The files `README.md`, `requirements.txt`, and the four Python files in `src/` are copied without code changes. The upstream datasets, paper, slides, images, IDE files, and compiled Python files are not included. To run the upstream training script, obtain the dataset from the original repository and place it in `dataset/` beside `src/`, then follow the original README. The training script's data paths are relative to `src/`.

The upstream repository does not contain a license file. This repository does not add a license or claim ownership of the upstream code.
